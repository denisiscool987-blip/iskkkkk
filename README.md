# OrbitOS 🚀

**A full desktop operating system experience that runs entirely in your browser.**

Version **1.1.0** — Polished Edition. Perfect for GitHub Pages. No build step, no backend.

## Features

- Window manager — drag, resize, minimize, maximize, **edge snap**
- Proxy browser — bookmarks + open in new tab
- Music player — Web Audio ambient tracks
- Games — Snake (D-pad + pause), Tic-Tac-Toe, 2048 (swipe), Memory
- Terminal, Notepad, Calculator, Paint (fill, line, rect, undo)
- File Explorer with README viewer + Open in Notepad
- Settings — 5 wallpapers, mute, clear data
- Keyboard: **Ctrl+W** close · **Ctrl+M** minimize · **Alt+Tab** switch · **Esc** dismiss
- Calendar popup, first-run tips, shutdown screen, UI sounds, mobile layout

## Deploy to GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js` to the **root** of a repo
2. Settings → Pages → Deploy from branch → `main` / root

## Local preview

Open `index.html` or run `python -m http.server 8080`.
