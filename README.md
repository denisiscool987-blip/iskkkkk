# OrbitOS

Full desktop OS experience in the browser. **v1.2.0** — Feature Pack.  
GitHub Pages ready. No install, no backend, no build step.

## Apps

Browser · Music · Games (Snake, Tic-Tac-Toe, 2048, Memory, **Minesweeper**, **Pong**) · Terminal · Notepad · Calculator · Paint · Files · **Sticky Notes** · **Task Manager** · **Weather** · Settings · About

## System

- Window snap, Alt+Tab, Ctrl+W / Ctrl+M / **Ctrl+R Run**
- Start menu **search**
- Calendar, **notification center**, mute, wallpapers
- **Screensaver** after 90s idle
- Shutdown screen, first-run tips, mobile layout

## Deploy

Upload `index.html`, `styles.css`, `script.js` to repo root → Pages → Deploy from branch.
